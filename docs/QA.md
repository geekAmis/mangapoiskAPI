Скриншоты: `docs/screenshots/android-*.png`, `node-*.png`,

### Переводы и источники

- MangaLib detail через `api.imglib.info` + `Site-Id: 1` возвращает русские
  названия; страницы идут с `img3.cdnlibs.org`;
- фильтр переводов по `source/translator/count` отдаётся variants-endpoint;
- «Во всеоружии»: MangaPoisk 274 главы, MangaLib 22 главы с командами
  ArticaProject/Hexe/Ньюби — variants работает;
- Remanga adapter реализован, но выключен по robots (`/api`);
- ReadManga/MangaDex остаются best-effort/выключенными из-за сети.

### Серверный архив

- глава 8 страниц MangaPoisk сохранена как ZIP 3.5 MB (страницы > 1 MB);
- повторный запрос страницы идёт через archive endpoint, не в источник;
- маленькие главы сохраняются BLOB-ами в SQLite;
- «скачать всё» ставит в очередь архивирование всех глав (endpoint
  `/api/v1/manga/{id}/warm`).

## Известные ограничения

- HTTPS пока не настроен: сайт на `:8088` по HTTP. Для release APK нужен
  домен + TLS.
- Android release APK не подписан.
- Нет iOS-сборки.
- SQLite на одном сервере; для нескольких инстансов нужна общая БД.
- MangaLib отдаёт только одну ветку перевода на главу (первую команду), не все
  ветки сразу.
- Новые главы кэшируются только после первого открытия (так и задумано).
